# 叙事结构规范（对 Agent 的硬性要求）

来源已核实：Minto 金字塔原理、MBB 咨询规范、Alley 的 Assertion-Evidence、Mayer 多媒体学习原则、
Knaflic/Cleveland-McGill 数据可视化研究。本文件把结论落成**可执行规则**，不是"设计建议"。

---

## 1. 幽灵稿优先（Ghost Deck）

**先只写标题，不写任何设计。**

输出一份纯文本大纲：每页一行，一行一个**完整句子**。这一步定稿之前，禁止写代码、禁止调用版式库。

理由：结构错了，排版再美也是废品；先排版再想结构，必然返工。

自检：把大纲的标题连起来读一遍，应该本身就是一篇通顺的论证。读不通 → 回去改结构。

---

## 2. 金字塔原理：结论先行

顺序固定为：

1. **结论/建议**（第 1 页或第 2 页就要出现）
2. 3–4 条支撑论据（每条独立成节）
3. 每条论据下的证据

**禁止**按"背景 → 过程 → 分析 → 结论"的时间顺序铺陈。高管要的是答案在前。

## 3. 行动标题：写结论，不写主题

每页标题必须是**完整句子**，且是这一页想让人记住的那句话。

| 反例（主题标题） | 正例（行动标题） |
|---|---|
| 市场概况 | 德国市场增速是欧洲其他地区的三倍 |
| 财务表现 | 毛利率连续两季下滑 1.2pp，主因是渠道折扣 |
| 系统架构 | 引入缓存层后 P95 延迟从 800ms 降到 120ms |
| 项目进展 | 项目按期推进，但供应商交付是唯一风险点 |

规则：
- 标题 = 这一页的结论。允许有人把全篇标题连读就明白全文的程度。
- 标题不得出现"概览 / 简介 / 背景 / 分析 / Overview / Introduction"这类空词。
- 正文只做**证据**，不复述标题。
- 副标题可以补充口径、范围、时间窗。

## 4. MECE：论据不重叠、不遗漏

同一层级的论据必须互斥且穷尽。常见骨架：
- 按环节：获客 → 转化 → 复购 → 流失
- 按结构：人 / 财 / 物 / 流程
- 按逻辑：现状 → 原因 → 影响 → 对策

两个论据讲同一件事（重叠）或漏掉一个明显维度（遗漏）都要打回重做。

## 5. 一页一意

一页只允许一个核心信息。有两个 → 拆两页。

## 6. 信号噪声比

删掉所有不为论点服务的东西：装饰性图形、无意义图标、无关配图、
渐变色块、Three.js 式炫技、口号式大字。

判断标准：把该元素拿掉，读者对结论的理解有没有变化？没有 → 删。

## 7. Assertion-Evidence（Alley）——比 bullet 更有效的默认结构

每页 = **一句断言** + **一块视觉证据**（图表/示意图/表格）。

研究结论：相比"标题 + 项目符号列表"，断言-证据结构提升理解与记忆，减少误解
（Alley, *The Craft of Scientific Presentations*, 4th ed., Springer 2018）。

因此默认版式是 `chart` / `matrix` / `table` / `timeline`，**`bullets` 是最后手段**。

## 8. 认知负荷（Mayer 多媒体学习原则）

| 原则 | 落成规则 |
|---|---|
| Coherence 一致性 | 删掉一切与结论无关的内容（图片、音效、花哨动效） |
| Signaling 信号 | 用**一种**方式强调重点（加粗/单色/框线，不要同时用三种） |
| Redundancy 冗余 | 不要"屏幕文字 + 逐字念稿"；文字要精炼 |
| Spatial contiguity 空间邻近 | 标注贴着被标注的对象，不要放图例远角 |
| Temporal contiguity 时间邻近 | 结论与其证据同页出现 |
| Segmenting 分段 | 复杂内容拆页，不要一页塞完 |
| Pre-training 前置 | 先用一页交代术语/口径，再做分析 |

## 9. 数据呈现（Knaflic / Cleveland & McGill）

- **图表选择**：连续数据 → 折线；分类数据 → 条形；只有一两个数 → 直接写大字；
  展示构成变化 → 堆叠条或瀑布图；**避免饼图、环形图、3D、双 Y 轴**。
- **感知精度排序**（Cleveland & McGill）：位置 > 长度 > 角度 > 面积 > 体积 > 颜色深浅。
  能用条形比长度解决的，不要用饼图比面积。
- 条形图**必须零基线**；折线图可以不从零起，但要在标注里说明。
- 网格线淡、少甚至去掉；不要粗轴线、不要图表边框、不要图例色块背景。
- 同页最多 5–6 条系列线；颜色只在需要区分时才用。
- **直接在图上标注**关键点，不要让人去对照图例。
- 每张数据图必须给出处（页脚 source）。

## 10. 排版硬规则（与 design-system.md 配套）

- **左对齐**。居中文本增加阅读成本；只有封面和分节页可居中。
- 标题字号**全篇一致**——字号一致是读者判断"这些观点同级"的视觉线索。
- 每页只有一个视觉主角；其余元素降低对比度。
- 每页留页脚：页码 + 数据出处。
- 正文字号下限：正文 ≥ 14pt，表格 ≥ 12pt，脚注 ≥ 9pt。

## 11. 收尾

最后一页必须给出**下一步**：谁、做什么、什么时候。不要用"谢谢聆听"占满一页。
