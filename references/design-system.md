# 设计系统（token 与版式规范）

`scripts/html-deck.mjs` 内的 `T`（token）与 `G`（几何）是**唯一事实来源**，本文件是它的可读版。
改设计 = 改 `T`，不要在调用侧写魔法数字。

## 页面与网格（px，1280×720 = 16:9 类PPTX 排版）

| 项 | 值 |
|---|---|
| 画幅 | 1280 × 720 px |
| 左右边距 | 60 px |
| 标题区 | y 44，高 80（字号 31→22 自适应量测） |
| 标题下分隔 | y 134：52 px 赭色短条 + 通栏浅灰细线 |
| 正文区 | y 152 → 666（高约 514） |
| 页脚 | y 678：来源（左）+ 页码（右） |

**所有版式的坐标都从上面推导。任何"我觉得放这儿好看"的手摆坐标都是违规。**
需要自由摆放的关系图（架构/流程/时序/ER）不在本库范围内——走 archify（见 structure-diagrams.md）。

## 颜色（角色制，不是色板抽奖）

| 角色 | 值 | 用途 |
|---|---|---|
| primary | `#16324F` 深墨蓝 | 标题、封面底、图表首选、表头 |
| accent | `#B4531F` 赭 | **每页最多一处**：短划线、序号、单个强调 |
| ink / ink2 / ink3 | `#14181F` / `#4B5563` / `#9AA1AB` | 正文三级 |
| rule / panel | `#E3E6EA` / `#F4F5F7` | 分隔线 / 面板底 |
| good / bad | `#2F6F4F` / `#A63D2A` | 瀑布涨跌、KPI 方向（tone 显式声明，不许从箭头方向猜） |

硬规则：**正文页同时出现的颜色 ≤ 2 个彩色**（primary + accent），其余用灰阶。
图表系列色最多 5 个：`#16324F / #B4531F / #64748B / #8C7A4B / #2F6F6B`。

## 字号（px，语义化，跨页一致）

| 语义 | 值 |
|---|---|
| 封面主标 | 44（自动收缩，下限 30） |
| 分节页 | 38 |
| 行动标题 | 31（自动收缩，下限 22） |
| 正文/列表 | 19（≤4 条时升 21） |
| 小字（轴标/表体） | 15–16 |
| 脚注/页码 | 12 |
| KPI 大数字 | 50（下限 26） |

标题字号全篇一致是硬规则——字号一致本身就是"这些观点同级"的视觉信号。
字体栈：微软雅黑 → 苹方 → Noto Sans CJK 回退，跨平台不装字体。

## 文本量测（防溢出）

`fitSize(text, w, h, {max, min})` 按 CJK 感知宽度（CJK=1em，拉丁≈0.52em）折行，
从 max 往下找装得下的字号。装不下报 `title-overflow` error——**修法是删字或拆页，不是硬塞**。
图表数值标签遵循同规则：首点 start 锚、末点 end 锚，绘图区四周留 padding 防截断。

## 版式清单（12 种，按叙事选）

| 版式 | 用途 | 硬限制 |
|---|---|---|
| `cover` | 封面 | — |
| `agenda` | 议程 | ≥5 项自动双栏 |
| `section` | 分节页 | — |
| `bullets` | 论点列表 | **≤5 条**，每条 ≤50 字宽 |
| `columns` | 2–3 栏对照 | ≤3 栏 |
| `chart` | 折线/柱/条（SVG+CSS 手绘，零依赖） | 系列数 ≤5，必须给 source；axisMin/axisMax 可指定 |
| `kpi` | 大数字行 | 2–4 个 |
| `matrix` | 2×2 优先级矩阵 | 恰好 4 格 |
| `table` | 数据表 | >10 行给警告；数值列用 aligns 右对齐 |
| `timeline` | 时间轴 | ≤6 节点 |
| `waterfall` | 归因瀑布 | 期初期末自动对账 |
| `closing` | 下一步（谁/何事/何时） | ≤4 条 |

选择顺序（默认优先）：`chart / kpi / matrix / table / waterfall / timeline / columns`
→ 实在没有结构化证据才用 `bullets`。

## 禁止事项

1. 手写 x/y 坐标（版式外的自由摆放）
2. 同页两个以上彩色
3. 阴影、渐变、艺术字、装饰性图形
4. 居中排版（封面/分节页除外）
5. 3D 图、饼图/环形图、双 Y 轴
6. 无出处却给数字
7. 用版式库硬画关系图（走 archify）
