# 交付前目检清单（渲染之后、交稿之前）

静态 lint 只能查结构（溢出、超量、缺出处）。**空间关系与审美必须看渲染图。**
流程：`node scripts/render-check-html.mjs out/deck.html out/renders` → 逐页看 PNG
→ 按下表过一遍 → 修 → 重渲。**没看过渲染图的稿子不算完成。**
（结构图产物同样适用本清单；archify 的 browser-check 是其自己的闸门，不能替代目检。）

## A. 结构层（每页都要过）

- [ ] 标题连起来读是一篇通顺的论证（金字塔检验）
- [ ] 每页只有一个视觉主角；扫一眼就知道先看哪
- [ ] 这一页删掉，论证会不会断？会断 → 留；不断 → 删
- [ ] 与结论无关的装饰（色块/图标/线条）已全部拿掉

## B. 空间层（最容易翻车，逐页目测）

- [ ] **留白成比例**：页边距视觉一致；半页空洞 = 版式选错，不是"风格"
- [ ] **对齐**：同一列的元素左边缘是一条直线；卡片间距处处相等
- [ ] **不拥挤**：相邻元素间距 ≥ 元素内部间距（分组清晰）
- [ ] **不贴边不截断**：文字距容器边缘有内边距；首末数据标签不越过绘图区
- [ ] 图表轴标签没有互相叠、没有截断；刻度文字完整
- [ ] 时间轴/瀑布的上下标签没有和轴线/柱子重叠

## C. 层级层

- [ ] 标题 > 副标 > 正文 > 脚注，四级一眼可分
- [ ] 强调手段只用了**一种**（加粗或赭色，不是三种叠加）
- [ ] 灰字只用于次要信息，没有成段的灰字正文

## D. 数据层

- [ ] 每张数据图页脚有出处
- [ ] 数字口径一致（同页同为环比/同比，单位写明）
- [ ] 条形图零基线；折线非零起点已在注释说明
- [ ] 数值精度合理（金额/比率保留两位小数，不四舍五入成整数）
- [ ] 图表颜色 ≤5 系列，且同一颜色全篇指代同一对象

## E. 中文排版细节

- [ ] 引号用中文引号「」或""，不用直引号
- [ ] 全半角标点统一（正文全角，数字/单位半角）
- [ ] 没有孤行（一行只剩一个字）与断词奇怪的折行
- [ ] 中英文之间留有间隙

## 处置规则

- 任何一条不过 → 修内容或换版式 → 重渲 → 重新过表
- Agent 无视觉能力时：委托视觉模型执行本清单（记录结论），或 lint 0 error +
  把渲染 PNG 交给用户并明确声明"未经目检"
